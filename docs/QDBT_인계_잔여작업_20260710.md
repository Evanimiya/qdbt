## 3. 확정된 결정 (2026-07-10)

**T3 — 용어 표준화: A안 확정.**
- 의미 모델: 제출서 = 추출 완료 시 **정본으로 동결(confirm)**. 클러스터링 = 개별 묶음 단위로 **채택(accept)**. 클러스터 단위는 대/중/소/세분류·품목까지 가변("[분류] 비교 단위" 설정과 연동).
- 범위: **UI·문서 용어 통일 + 신규 코드부터 표준 적용.** 전면 코드 리네임은 T4 작업과 함께 점진적으로.

**T4 — 되먹임 분리: 논리 분리 우선 → 물리 분리 후속.**
- 지금은 논리 분리(정본 컬럼 vs 비교 결과 컬럼 경계 명확화)로 구현·테스트. 테스트 마무리 후 물리 테이블 분리로 승격. 코드를 나중에 물리 분리가 쉽도록 경계 뚜렷하게 작성.

**T10 — item_id 동결: 서비스 계층 강제(권장 3, 필요 시 1+3).**
- 모든 쓰기를 단일 서비스 경로로 통과시키고 그 지점에서 확정 항목 잠금 가드. DB 트리거는 과함. T9(상태 모델)에서 확정 상태 정의 후 얹음.

> 세 결정 모두 "나중에 필요하면 재수정" 여지 있음(특히 T4는 물리 분리 승격 예정).

권장 실행 순서: **T3(기준) → T4(논리 분리) → T9(상태 모델) → T10(동결) → T11·T12** · 병합기능(T8)·후순위 UI(T13·T14)는 병행/후속.
