## 1. b 완료 작업 (task1-link-canvas → main 병합)

### 버그 수정
- 시트 선택 보존(sessionStorage) + 시트전환 성능(classify 워크북 캐시) + 미선택 시트 추출 오류.

### 개선
- 통화 드롭다운(USD·EUR·JPY·CNY·KRW+직접입력, 타겟 KRW) + 안내문 폰트 축소.
- 추출화면 액션버튼 한 줄, 카탈로그 매칭 라벨 명확화(유지).
- 비교단위 트리: 모두 펼치기/접기 + [분류] 펼침 + 버튼 4개.
- 장비 수량 = 제출서별 `unit_count`, 대당단가·special nego = 총액/n 배분.
- 다중시트 연계 진입버튼 상시 노출.

### 연계 캔버스(/link)
- 목업 3열 캔버스 복원 + 드래그드롭 수기조정(실동작).
- 모든 레벨 가지(묶음) 재부모화 — 서브트리 통째 이동(Δ=0), 순환 방지.
