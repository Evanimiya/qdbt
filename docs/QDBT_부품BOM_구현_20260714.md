## 데이터 모델
- **품목 = 집계 잎**(is_header=0, 레벨5=품명): 품목수량·품목단가·품목금액.
- **부품 = 품목 하위 표시노드**(레벨6=부품, `bom_part`→**is_header=1=총액 제외**):
  `part_qty`·`part_price`·`part_amount`(=부품수량×부품단가).
- **경제구조**: 품목단가 = Σ파트금액(per-unit BOM), 품목금액 = 수량×단가, **총액 = Σ품목금액**
  (부품 파트금액은 단가 내역 → **미포함, 이중계상 방지**).

## 구현
1. **스키마**: `submission_items.part_qty/part_price/part_amount`(자동 마이그레이션, create_app에서 보장).
2. **검증 게이트** `core.totals.check_bom`: ① Σ파트금액≈품목단가(불일치 `bom_cost`) ② 수량×단가≈금액
   (`bom_line`) · **per-unit vs total 애매성** 감지(Σ파트≈금액이면 `bom_scale` 경고, 자동수정 없음).
3. **추출** `extract_by_mapping`: `part_qty/price/amount` 역할 + 자동감지(부품 경제열이 qty/price/amount로
   새지 않게 우선순위). BOM 모드(부품 경제열 매핑 시): 품목행=집계 잎, 부품행(name 빈칸·part 채움)=
   품목 하위 방출(bom_part·레벨6·cat_levels=[분류,5]/leaf6). 표준구조 자동감지, 부모 품목 없는 부품행은
   자기 경로 폴백. **BOM 미매핑이면 기존 [부품] 승격 유지**(실샘플 15개 Δ=0).
4. **저장** `insert_items_bulk`: part_* 컬럼 + `bom_part`→is_header=1.
5. **업체 비교 펼쳐보기**(d2724ba 캔버스): `get_cluster_leaves`가 품목 셀에 `parts[]` 첨부(부품↔품목
   전체경로 매칭). 모달에서 품목 **-/+ 토글**(엑셀 그룹 UX) → 부품 서브행(부품수량×부품단가=파트금액)
   **업체별 비교** + **부품별 최저가 🏅**. 기본 접힘, 헤더 유지, **총액 불참**(단가 내역·표시전용).

## 미니 예시
```
납블록: 수량2 · 단가300 · 금액600      [품목=집계 잎]
  └ 순납강판  3×50=150   (A사)         [부품=is_header=1, 총액 제외]
  └ 볼트      1×150=150
Σ파트=300=단가 ✓ · 2×300=600=금액 ✓ · 총액=600(파트금액 미포함)
업체 비교: 납블록 [－] 펼치면 순납강판·볼트 행이 A사/B사 파트금액 비교(최저가 🏅).
```
