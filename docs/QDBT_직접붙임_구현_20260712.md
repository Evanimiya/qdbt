# QDBT 구현 보고 — 중간 레벨 부재 = '직접 붙임' 표준 (2026-07-12)

> 결정(사용자 확정): 중/소/세가 빠지고 품목이 대분류에 바로 붙는 경우 → **(A) 대 > 품목 직접**.
> 목업 `docs/mockup_직접붙임_렌더.png` 승인. `_prev_val` 상위값 복제 제거, extract·stitch 통일.
> 매칭 3단계 원칙 유지(자동 채움 금지, 애매하면 미연계→사람).

## 1. 판단 규칙 (결정론적 코드, 순서대로)

| 순 | 조건 | 처리 | 구현 |
|---|---|---|---|
| ① | 그 레벨 열 **미매핑** | **직접 붙임**(스킵, placeholder 없음) | extract/stitch 조립 |
| ② | **병합셀/이어받기**(fill-down, last_cat) | **정당 상속 유지**(같은 값) | 유지 |
| ③ | **번호가 레벨 존재 암시**(1.2.1인데 **이름만 빔**) + 금액 | **미연계**(⟨이름 누락⟩ 보존, 계상) | `_stitch_seq` |
| ④ | **형제 비교**: 같은 부모 형제엔 그 레벨 있는데 이 행만 빔 | **미연계**(placeholder). 형제 전부 비면 **직접** | extract 사전패스 |
| ⑤ | 위 어디에도 안 걸림 | **직접 붙임** | 기본 |

- **`_prev_val` 상위값 복제 제거**(`extract_by_mapping.py`): 대분류 이름을 중/소에 베껴 `재료비 >
  재료비 > 재료비 > 납블록` 가짜 노드를 만들던 레거시 삭제. (②의 병합 상속과는 다름 — ②는 유지.)
- **placeholder(⟨미연계·N분류⟩)는 ③④의 '누락 의심'에만**. ①⑤ 정상 빈 계층엔 미사용.
- **경로 간 통일**: 단일시트 `extract_by_mapping`·다중시트 `stitch` 둘 다 직접 붙임 기준.

## 2. 렌더

- 잎을 대분류에 직접 붙이면 트리·캔버스가 **대 > 품목**으로 보존(중간 재생성 금지).
- 잎 열은 leaf-aware 라벨로 **'품명'**(`_link_canvas.html` colHeaderLabel, 기존 `c9c78ce`).
- 얕은 항목(대>품목)·깊은 항목(대>중>소>품목) 공존.

## 3. UI — 잎을 상위 가지에 직접 잇기

- **캔버스 드래그**: `canDropOn`이 leaf 드래그를 무제한 허용 → 잎을 **대분류 포함 임의 상위 가지**에
  드롭 가능. `bulk-reparent`가 잎 `path = target`(대분류)로 설정 → 트리 **대 > 품목 직접**(총액 Δ=0)
  end-to-end 확인.
- **residual 재지정 드롭다운**: 후보 경로의 **모든 조상 프리픽스**(재료비 · 재료비 > 기구부 …)를
  선택지에 추가 → 잎을 **대분류에 직접** 재지정 가능(`_build_residual_view`).
