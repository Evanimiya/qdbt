## 발견된 버그 · 수정 · 결정필요

### ✅ 수정 (Δ=0 게이트 통과)

- **합계행 미탐 → 이중계상 (S5 5-dc / 5-det)**: 합계 마커가 품명 셀에 있고 분류 셀 값이 조인 문자열 뒤에 붙는 경우(`"소계 재료비"`) `is_total_label` 의 `endswith` 앵커가 무력화돼 소계·합계 행이 잎으로 계상(이중계상)됐다. `_is_total_row`(stitch)·`detect_total_rows`(extract) 를 조인 검사 + **셀 단독 검사**로 보강. 실샘플 **15개 / 31시트 / 3446행** 에서 per-cell 신규 발동 **0건 → Δ=0** 확인 후 반영. (병합된 대분류가 소계행에 채워지는 흔한 양식에서 발생.)

### ⚠️ 결정 필요 (자동수정 보류 — 회귀 위험)

- **seq 모드 leaf 시트 은닉 소실 (S6 6f)**: 정수번호+금액 시트(role `leaf`)가 점계층 세부(`seq_leaf`)와 함께 오면 seq 모드가 발동, `_stitch_seq` 가 `seq_leaf/seq_list/seq_tree` 만 방출 → `leaf` 시트가 residual·roll-up 흔적 없이 통째 소실. 실샘플 C3 `공종목록`은 정본합과 우연 일치(요약)해 총액엔 무해하나, **독립 breakdown이면 금액 소실**. 안전 수정은 leaf 시트를 residual passthrough로 방출 후 roll-up 정합 필요—이름매칭 실패 시 C3 총액 회귀(3.35B) 위험. 설계결정 필요.

- **band 요약 고유비용 은닉 소실 (S7 7-4)**: band 아키타입은 요약(갑지)시트를 골격으로만 써, 요약에만 있는 비용(부대비 등)이 소실. band 금액 무조건 방출 시 band-JOIN(C2)에서 이중/삼중 계상 회귀 → 안전 자동수정 불가, 설계결정 필요.

- **시트 간 동일항목·분류명만 상이 (S1 1e)**: `_dedup_and_rollup` 완전중복 키가 분류경로를 포함해, 같은 품명·규격·금액이 다른 분류명이면 병합 안 됨(잠재 이중계상). 분류가 실제로 다르면 별개 항목일 수 있어 자동병합 위험 → '분류 무관 dedup' 옵션 여부는 설계결정 필요.

- **로케일 모호 파싱 (S7 7-1 '1.000', 7-5 '1-5')**: 통화/로케일 힌트 없이는 유럽식 천단위·범위표기 해석이 모호. 도메인(KRW 정수 우세) 기본정책 유지, 힌트 도입은 결정 필요.
